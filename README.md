# Excel Revision: Employee Data Analysis

## 📌 Project Overview
This project focuses on building an employee dataset and performing exploratory data analysis using advanced Excel functions and dynamic formulas. The goal is to analyze workforce metrics, track salary distributions, evaluate department costs, and provide actionable business insights for HR decision-making.
